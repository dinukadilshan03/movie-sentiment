# Data Collection

## Present These Points

- Data source: **secondary Rotten Tomatoes movie and review data**
- Final dataset used: `data/final/final.csv`
- Raw final dataset size: **4,072 movies** and **29 variables**
- Reviews were limited to the **first 10 days after theatrical release**
- Key features created: `audienceScore`, `initial_combined_sentiment_score`, `log_initial_review_count`, `initial_sentiment_x_log_review_count`, `log_box_office`

## Important Numbers

- Inferential sample: **3,747**
- Predictive sample: **3,746**

## Key Message

- The dataset is large enough and suitable for descriptive, inferential, and predictive analysis
